# 변경 이력

공개 가능한 결과 중심 변경 요약이다. 날짜 아래에 같은 날의 변경을 모으고 최신 항목을 위에 둔다.

## 2026-11-14

### 변경 요약 (리뷰 남은 결함 수정)

- 가이드: 공동 편집 중 새로 만든 블록의 위치 식별자가 저장할 때마다 바뀌어 그 블록에 남긴 학생 질문의 위치가 끊기던 문제를 고쳤다. 편집기가 식별자가 없거나 겹치는 블록에 바로 식별자를 준다. 가이드 생성 재전송 비교가 이미지 설명·제목에 `>`·`<`가 있어도 같은 내용을 알아본다.
- 읽기 화면: 체크 칸 구조 없이 저장된 체크 항목(가이드 가져오기로 넣은 페이지 등)도 체크 칸이 보인다. 가이드 가져오기는 편집기와 같은 구조로 저장한다.
- 관리자 달력: 기간 읽기 오류가 그 기간을 다시 읽거나 읽은 기간으로 옮기면 사라지고, "다시 시도"는 보던 기간을 이어 읽는다. 학생 한 명 일정도 뒤로·앞으로 돌아왔을 때 다른 곳에서 지운 항목이 남지 않는다.
- 업무함: 앞 행 저장이 늦게 실패해도 다른 행의 되돌리기 안내를 덮지 않고, 같은 행의 늦은 결과가 마지막 요청을 뒤집지 않는다.
- 과제: 두 화면이 같은 과제를 동시에 고쳐 저장하면 늦은 쪽에 "먼저 고쳤습니다"를 보인다(그 사이 삭제됐으면 찾을 수 없다고 보인다).
- 디깅: 트랙 추가 창에서 카멜롯 키판을 연 채 Esc를 누르면 키판만 닫힌다.
- 이미지 보기: 이전·다음으로 넘겨도 버튼의 키보드 초점이 남는다.
- 파형: 머리글보다 짧게 끝나는 FLAC(잘리거나 손상된 파일)의 파형을 실제 길이 전체에 펼친다. 이미 만든 파형은 다시 만들지 않는다.
- 이전 초안 보관함: 실시간 편집으로 옮겨 간 문서 종류의 기기 초안만 보인다(지금 쓰는 댓글·피드백·제출·메모·과제 폼 초안이 옛 초안으로 보이던 문제).

## 2026-11-13

### 변경 요약 (학생별 가이드 열람 권한)

- 가이드: Stann이 학생마다 가이드를 닫힘·전체·선택 중 하나로 정한다(학생 상세 · 개요의 "가이드" 구획, 고르는 즉시 저장). "선택"은 열어 줄 페이지를 하나씩 고른다. 새로 초대한 학생은 닫힘으로 시작한다.
- 학생 화면: 가이드가 닫힌 학생은 메뉴에 "가이드"가 없고 주소로 들어오면 "아직 열린 가이드가 없습니다" 안내만 본다. 열리지 않은 페이지의 본문·이미지·질문 위치는 받지 못하고 그 페이지로 질문을 만들 수 없다. 이미 남긴 가이드 질문은 그대로 보이고 닫힌 페이지로 가는 링크만 빠진다.
- 기술: D1 migration `0028_guide_access`(새 표 `guide_access`·`guide_access_pages`, 이미 가입을 마친 학생을 "전체"로 옮기는 backfill 포함). 코드보다 먼저 적용해야 한다.

### 변경 요약 (코드 리뷰 뒤 결정 반영)

- 공동 편집: 다른 편집자(관리자·학생)가 넣은 본문 이미지도 저장할 때 그 문서에 연결된다(편집 권한이 있는 사람이 넣은 이미지만). 복원과 겹친 입력을 되살린 뒤 응답이 늦어 다시 시도해도 같은 내용이 두 번 들어가지 않는다. 편집 화면을 닫았다가 곧바로 다시 열면 이 기기 보관이 닫혀 입력 저장이 오류로 멈추던 문제를 고쳤다(화면을 닫을 때는 보관을 지우지 않고, 로그아웃·계정 전환 때만 지운다). 병합 규칙이 이미 들어간 내 삽입을 바로 옆 구간에서 알아본다(문서 전체를 뒤지지는 않는다).
- 로그인: 비밀번호 지문이 없는 예전 로그인 상태는 받지 않는다. 해당 기기는 한 번 다시 로그인한다.
- 캘린더: 캘린더를 다시 지정해도 가져온 일정이 한 벌 더 생기지 않는다. 바깥 캘린더에서 지운 레슨은 포탈에서 지우지 않고 연결만 끊는다. 다른 Google 계정으로 다시 연결하면 이전 계정의 캘린더 지정을 정리한다. 바깥에서 지워져 연결이 끊긴 레슨은 포탈에서 옮기면 바깥 캘린더에 다시 만들어진다. 캘린더 지정을 풀 때는 포탈에서 고친 뒤 아직 보내지 못한 변경을 먼저 보낸다. 오래된 매일 반복 일정 때문에 연결한 캘린더가 통째로 읽히지 않던 문제를 고쳤다(보이는 기간 안의 일정만 2,000건으로 센다).
- 커뮤니티·Q&A: Stann은 종료된 질문에도 바로 답변할 수 있고, 답변을 등록하면 질문이 "답변 완료"로 다시 열린다. Stann이 휴지통으로 보낸 게시물·질문은 Stann만 되살린다. 학생의 휴지통에는 "Stann이 지움" 표시와 보관 기한이 함께 남고 복원 버튼은 보이지 않는다. 댓글은 5,000자까지다. 게시물 수정의 "취소"는 화면만 닫고 함께 쓰던 작업본은 그대로 둔다. 게시한 뒤에 고친 내용을 버리려면 "게시된 글로 되돌리기"를 쓴다(함께 고치던 사람이 넣은 내용도 사라지므로 한 번 더 확인한다).
- 노트: 강사 메모 이력을 정리해도 바로 앞 내용 한 건은 남는다. 새 노트의 수업 타이머가 같은 탭에서 새로고침해도 이어진다.
- 과제: 과제·정기 과제 "고치기"도 고치던 내용을 이 기기에 보관한다. 그 사이 과제가 바뀌었으면 되살리기만 하고 저장은 막는다.
- 개인정보처리방침: 알림(기기 구독 정보와 브라우저 알림 서비스), 디깅 링크의 곡 정보 조회, 포탈 안 YouTube·SoundCloud 재생, 커뮤니티에서 보이는 표시 이름을 적었다. "이메일 주소 전체는 다른 학생에게 보이지 않는다"는 같은 날의 코드 리뷰 수정과 함께 나가야 사실이다.
- 기술: D1 migration `0027_list_query_indexes`(기존 표에 index 5개만 추가). `wrangler.scheduled.toml`을 `wrangler.toml`과 같은 placement·메일 binding으로 맞췄다. 호출처가 없던 서버 초안 동기화 client 코드를 지웠다.

### 변경 요약 (전체 코드 리뷰 수정)

- 보안·개인정보: 로그인 뒤 돌아가기 주소와 알림 이동 주소가 다른 사이트로 넘어가지 않게 검사를 보강했다(`/.//host` 꼴). 커뮤니티 글·댓글·Q&A 응답에 다른 사용자의 이메일 전체가 실리지 않는다(이름이 없으면 이메일 앞부분만 표시 이름으로 쓴다). 쓰지 않는 관리자 seed script를 지웠다.
- 편집기: 코드 블록에서 Tab이 공백 2칸을 넣는다(전에는 아무것도 들어가지 않았다). 링크 넣기의 표시 글자를 markdown으로 다시 읽지 않는다. 저장 대기 중에 앱 안에서 다른 화면으로 가도 마지막 입력이 저장된다.
- 플레이어: 준비되기 전에 멈춘 영상·SoundCloud가 준비된 뒤 저절로 재생되지 않는다.
- 업로드·날짜: 브라우저가 `audio/x-m4a`·`audio/mp3`·`audio/x-wav` 등으로 알려 주는 음원 파일을 받는다. 레슨·일정 시각은 한국 시간 입력 또는 시간대가 붙은 ISO 형식만 받고 2월 30일 같은 없는 날짜를 거절한다.
- 권한 화면: 다른 사람의 휴지통 게시물, 다른 학생의 노트 이력 주소는 "없는 페이지"로 보인다(전에는 오류 화면).
- 커뮤니티: 댓글을 지우지 못하면(게시물이 휴지통에 있음 등) 이유를 보이고 목록을 다시 불러온다. 공지 고정을 바꾸면 목록 순서가 바로 바뀐다.
- 오류 화면의 "다시 시도"가 서버 화면을 다시 불러온다.
- 캘린더: 일정을 옮기면 열려 있던 상세 칸이 옮긴 일정을 따라간다. 연결된 캘린더의 "다음 레슨"은 90일 안의 일정만 본다.
- 디깅: 처음 여는 순간 두 창이 겹쳐도 기본 열이 한 벌만 생긴다. 트랙 추가 줄에서 늦게 도착한 링크 정보가 이미 적은 값을 덮지 않고, 지운 숫자 칸이 0으로 저장되지 않는다.
- 알림: 기기 구독 확인을 계정마다 한 번만 한다.

## 2026-11-11

### 변경 요약 (수업 도구 라이브 큐)

- 수업 노트를 트랙 단위로 정리한다: 트랙은 제목 줄(`트랙 09 · 곡명`), 곡 피드백은 그 아래 목록, 곡 전환 피드백은 트랙 사이의 회색 칸(`⇄ 전환 09 → 10`)으로 구분해 보인다. 학생 화면에도 같은 모양으로 보이며, 예전에 쓴 `▸ 트랙 N` 줄도 트랙으로 읽는다.
- 수업 도구 맨 위에 지금 트랙과 "다음 곡으로"(⌥N)를 둔다. 누르면 전환 칸과 다음 트랙 제목이 함께 들어가고 커서가 전환 칸에 놓인다. 곡 제목은 미리 적거나 비워 두고 나중에 고친다. "곡 피드백"(⌥F)·"전환 메모"(⌥M)는 커서 위치와 관계없이 지금 트랙 끝에 줄을 연다.
- 빠른 태그(비트매칭·루프·EQ·커브·잔음·볼륨·프레이즈·선곡·키)를 누르면 쓰고 있는 줄 앞에 굵은 라벨로 붙는다. 세트 목록은 트랙마다 곡·전환 피드백이 있는지 보이고, 누르면 그 트랙으로 간다. 트랙 번호는 본문에서 센다.
- 믹스 타이머와 비공개 메모는 접어 둔다. 타이머가 돌면 다음 곡·전환 칸에 시점이 붙는다. 좁은 화면은 아래 고정 막대에서 태그·곡·전환·다음 곡을 바로 누른다.

### 변경 요약 (편집기 Tab 들여쓰기)

- 노트·가이드·게시물·Q&A 편집기에서 Tab을 누르면 초점이 옆 버튼(수업 도구 등)으로 가지 않고 편집기 안에서 동작한다: 문단·제목은 들여쓰기(최대 6단계), Shift+Tab은 내어쓰기, 목록은 단계 이동, 표는 다음 칸, 코드 블록은 공백 2칸. Esc를 누르면 편집 영역에서 나와 Tab으로 다음 조작으로 간다.

## 2026-11-10

### 변경 요약 (전체 페이지 로딩·반응 없음 정리, 버그 점검)

- 대시보드와 커뮤니티가 같은 셸(사이드바·위쪽 막대)을 함께 써서, 오갈 때 셸 전체가 다시 그려지지 않고 본문만 불러오는 중으로 바뀐다(주소는 그대로).
- Q&A 상태 탭은 서버를 거치지 않고 바로 바뀐다(주소만 바꿈). Q&A·노트·커뮤니티 검색은 문서를 다시 받지 않고 앱 안에서 이동한다.
- 과제 알림·오늘 할 일·관리자 레슨 알림은 정식 주소로 바로 열고, 예전 주소는 화면을 그리기 전에 넘긴다(두 번 불러오던 문제).
- 알림을 누르면 열린 화면 안에서 이동한다. 본문 안 포탈 링크는 앱 안 이동, 다른 사이트 링크는 새 탭으로 연다.
- 학생 상세 탭은 누르는 즉시 대기 표시가 보이고, 전체 노트 학생 필터는 고른 값을 바로 보인다.
- 버그 점검 수정: 파형은 올린 사람·관리자가 다시 저장하면 다른 사람이 먼저 쓴 값을 바꾸고 MP3 길이 검사를 좁혔다. 화면을 떠나면 파형 계산을 멈춘다. 미니 플레이어 높이가 바뀌어도(YouTube 안내 줄) 입력줄이 가려지지 않는다. 피드백 고치기에서 Esc가 보관본을 지우지 않는다. 가로 화면 안전 영역, 위쪽 막대 높이 1px, 미니 플레이어 재생 실패 안내, 멈춘 채 파형을 옮겨도 재생하지 않음, 화면 읽기 알림 누락, 업무함 되돌리기 실패 복구.

### 변경 요약 (가이드 목차 분리·위쪽 이동 막대)

- 가이드: 왼쪽 목차를 페이지와 분리했다. 페이지를 옮겨도 목차는 그대로 있고 본문만 불러오는 중으로 바뀐다(편집 화면은 목차 없음).

- 초안 선택창은 실제로 다른 내용일 때만 뜬다. 마지막 저장과 같거나 더 오래된 계정 작성본은 조용히 정리하고, 같은 작성본에 대해 한 번 고른 선택은 다시 묻지 않는다. 다른 기기의 다른 내용은 지금처럼 선택으로 보호한다.
- Stann이 수업 노트를 쓰는 동안 학생 화면이 새로고침 없이 따라온다. 학생이 열어 둔 노트 문서와 캘린더 패널은 탭이 보일 때 몇 초 간격으로 확인해 바뀐 본문만 제자리에서 바꾸고, 학생 노트 목록·홈은 창으로 돌아올 때와 30초마다 조용히 다시 받아 새 노트를 보인다(입력 중이면 건너뛴다).
- 노트를 고친 뒤 뒤로 가기로 노트 목록·학생 홈·관리자 홈 캘린더에 돌아오면 바뀐 제목·날짜와 새 노트를 다시 받아 보인다. 같은 브라우저의 다른 탭에서 쓰던 작성본은 한 탭의 제출 정리로 지워지지 않는다.
- 기술: 계정 작성본 비교에서 입력마다 바뀌는 operation ID를 뺐고, 폐기 뒤 늦게 도착한 저장이 작성본을 되살리지 못하게 서버가 막는다. 노트 head(version·수정 시각)만 읽는 조회를 본인·관리자 권한으로 추가했다. 데이터베이스 migration은 없다. 실제 브라우저 두 창 동작(Stann 입력·학생 자동 갱신)은 별도 확인 대상이다.
