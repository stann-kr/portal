# 변경 이력

공개 가능한 결과 중심 변경 요약이다. 날짜 아래에 같은 날의 변경을 모으고 최신 항목을 위에 둔다.

## 2026-08-05

### 포털 shell과 접근성 정리

#### Changed

- 학생과 관리자 포털의 중복 section 상태·navigation 구현을 공통 shell로 통합했다.
- 본문 skip link, main·nav·aside landmark, 현재 section, icon control 이름과 focus 상태를 정리했다.
- 학생 roster를 mobile list와 desktop table로 분리하고 확장 행을 실제 button으로 조작하게 변경했다.
- 캘린더 navigation에 좁은 화면 overflow 전략을 추가하고 고정 높이를 viewport 기반 범위로 교체했다.

#### Added

- 대시보드 데이터 대기 시 최종 구조를 반영한 skeleton을 표시한다.
- 대시보드 조회 실패 시 맥락 안에서 다시 시도할 수 있는 오류 화면을 추가했다.

### 관리자 업무함 도입

#### Added

- 관리자 포털의 기본 진입점에 미답변 Q&A, 피드백 대기 과제, 7일 이내 레슨을 모은 업무함을 추가했다.
- 실제 처리 화면으로 바로 이동하는 작업 목록과 학생·일정 section 바로가기를 추가했다.
- 질문 대기 시간, 과제 제출 시간, 레슨 기간 정렬 규칙을 단위 테스트로 고정했다.

#### Security

- 과제 피드백 조회가 인증된 본인 또는 관리자에게만 허용되도록 읽기 권한 경계를 보강했다.

#### Changed

- 관리자 상위 navigation을 업무함·학생·일정·공지·커뮤니티 순서로 정리했다.
- 과제 상세의 돌아가기 경로와 label을 현재 역할에 맞게 제공한다.

### 학생 오늘 화면 도입

#### Added

- 학생 포털의 기본 진입점에 다음 일정, 피드백이 있는 제출, Q&A 상태, 최근 공지를 모은 오늘 화면을 추가했다.
- 노트, 질문, 일정·디깅 기록으로 바로 이어지는 빠른 행동을 추가했다.
- 다음 cue와 학습 상태 분류 규칙을 단위 테스트로 고정했다.

#### Changed

- 기존 캘린더 section을 워크스페이스로 정리하고 커리큘럼·과제·통합 기록 기능을 그대로 유지했다.
- 포털 section navigation에 현재 위치와 keyboard focus 상태를 명확히 표시했다.

### 포털 디자인 기반 정리

#### Changed

- 포털의 중립색, 주요 행동, 의미 상태, focus, radius, elevation, motion token을 공통 theme으로 정리했다.
- Q&A와 학습 상태의 label·색·icon 기준을 공통 registry로 통합하고 단위 테스트를 추가했다.
- portal navigation, status badge, section header, empty state 공통 component를 추가했다.
- 운영체제 설정을 따르는 dark theme과 reduced motion fallback을 추가했다.

#### Docs

- 실제 token과 component 사용 규칙을 설명하는 디자인 시스템 문서를 추가했다.

### 캘린더 token·HTML 입력 보안 회귀 테스트

#### Security

- 캘린더 구독 token의 secret 누락, 학생 불일치, 형식·서명 변조 거부 경로를 자동화했다.
- rich text에서 script, inline event handler, 위험 URL protocol이 제거되는지 회귀 테스트로 고정했다.

### 인증·권한 가드 회귀 테스트

#### Security

- 인증 세션, 관리자 역할, 본인·타인 소유권 경계를 순수 검증 함수로 분리했다.
- 미인증·student·admin·owner·cross-user 허용·거부 경로를 자동 테스트로 고정했다.

### 공개 문서 탐색과 개발 우선순위 정리

#### Docs

- 문서 허브에 목적별 읽는 순서와 현재 개발 우선순위를 추가했다.
- 요구사항 상태 의미와 기술 명세의 품질 경계를 명확히 하고, 트러블슈팅 대표 사례로 바로 이동할 수 있게 정리했다.

### HTTP client 하위 의존성 보안 패치

#### Security

- 런타임 의존성 경로에서 사용하는 HTTP client를 보안 패치 버전으로 제한했다.
- 지원 Node.js 최소 버전을 패치 의존성 계약에 맞춰 `20.18.1`로 명확히 했다.

## 2026-08-03

### 개발용 관리자 seed 격리

#### Security

- 관리자 seed를 로컬 development 환경과 명시적 opt-in이 모두 있는 경우로 제한했다.
- 관리자 비밀번호의 명령행 입력과 SQL·해시 출력을 제거하고 환경 변수와 prepared statement를 사용하도록 변경했다.
- 환경 guard, 입력 binding, password hash를 검증하는 회귀 테스트를 추가했다.

### 로컬 개발 DB 재현성 복구

#### Fixed

- 불일치하던 로컬 D1 상태를 빈 DB로 재생성하고 `0000`부터 `0007`까지 전체 migration을 다시 적용했다.
- 로컬 적용 이력, 실제 스키마, versioned SQL의 컬럼·외래키·인덱스가 일치하는 상태를 확인했다.

## 2026-08-02

### Migration 생성 이력과 재생 검증 복구

#### Fixed

- 기존 SQL을 변경하지 않고 누락된 Drizzle journal·snapshot을 `0007`까지 복원했다.
- 다음 schema 생성이 과거 변경을 다시 만들지 않도록 current schema 기준 무변경 상태를 확인했다.

#### Added

- SQL·journal·snapshot 대응, empty DB replay, current schema 구조와 SQLite 무결성을 한 번에 검사하는 `npm run db:check`를 추가했다.

- 배포 환경에서 데이터베이스 바인딩 접근 방식이 달라 인증이 실패하던 문제를 해결했다.
- 인증 콜백 경로를 미들웨어 대상에서 제외해 무한 리다이렉트를 차단했다.
- 구 배포 어댑터 잔재로 개발 서버가 죽던 문제를 정리했다.

### [v0.6.0] — Cloudflare 배포 어댑터 전환

#### Changed

- 빌드 스크립트와 배포 진입점, 자산 경로를 새 어댑터 기준으로 변경했다.

#### Changed

- 검색 파라미터 훅을 경계 컴포넌트로 감싸 프리렌더 오류를 해결했다.
